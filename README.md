# CS361-MainProgram

A Multiplayer Microservice with accounts and registration for games.

## Installing dependencies

To install the dependencies run `npm install`

## To run the Website/Server

To run the server please run `npm start`

## To run the test client

Either use `dotnet run <websocket> <api_key>`, or an IDE with the arguments

Or use the pre-packaged executable, and supply the arguments.
